# ReciclaYA ♻️

Página web sobre compra y venta de reciclaje.

## Descripción

ReciclaYA es un sitio para conectar personas y empresas interesadas en comprar o vender materiales reciclables de forma fácil.

## Páginas

- `index.html` — Inicio
- `productos.html` — Productos disponibles
- `empresas.html` — Empresas
- `registro.html` — Registro de usuarios
- `login.html` — Inicio de sesión
- `contacto.html` — Contacto

## Tecnologías

- HTML
- CSS
- JavaScript

## Cómo usarlo

1. Clona el repositorio:
   ```bash
   git clone https://github.com/ccardenasdev/ReciclaYA.git
   ```
2. Entra a la carpeta del proyecto:
   ```bash
   cd ReciclaYA
   ```
3. Abre `index.html` en tu navegador.
